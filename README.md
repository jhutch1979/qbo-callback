# qbo-callback

Static GitHub Pages site for a private, internal QuickBooks Online app of Sunnies Up North LLC.

- `index.html` - OAuth callback page; displays the current URL and `code`, `realmId`, `state` locally in the browser. Sends nothing anywhere; no external scripts.
- `privacy.html` - Privacy policy
- `eula.html` - End user license agreement

Site: https://jhutch1979.github.io/qbo-callback/
